# TeXstudio Espresso 4.9.9-espresso-1 — source and build information

The release uses the exact source revisions below. Source downloads are separate from app downloads; third-party source archives are linked at their original hosts.

- [Editor source](https://github.com/DominikPeters/texstudio-espresso/tree/09a2267b01f6d0d3cfb4fc775125230cae1fcedc).
- [Shared TeXpresso engine source](https://github.com/DominikPeters/texpresso/tree/a33eded4f6a5b62a3c94e91572496588e8ff4b87).
- [Mac packaging/icon source](https://github.com/DominikPeters/texstudio-espresso/tree/b8fc31c7bbe6cda6452b69eb12b4a2cddafcd5c7); editor and engine implementation retained from the original release.
- [Build instructions](https://github.com/DominikPeters/texstudio-espresso/tree/b8fc31c7bbe6cda6452b69eb12b4a2cddafcd5c7/native).
- [Original build recipes, patches and configuration](https://github.com/DominikPeters/texstudio-espresso/releases/download/4.9.9-espresso-1/source-info.zip).
- [Machine-readable dependency URLs and SHA-256 hashes](https://github.com/DominikPeters/texstudio-espresso/releases/download/4.9.9-espresso-1/source-manifest.json).

A recursive clone obtains the pinned engine submodule. GitHub’s automatic source ZIP/tarball does not include submodule contents. Dependency versions differ between platforms; the small build-information download preserves the original platform manifests. Apply the recorded patches and recipes when rebuilding those dependencies.
