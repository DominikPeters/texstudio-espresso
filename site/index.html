TeXstudio Espresso

A fork of the TeXstudio LaTeX editor with a live preview. The preview is produced by TeXpresso and updates while you edit, without running a separate compile.

Download TeXstudio Espresso Other releases on GitHub Version 4.9.9-espresso-1

Live preview

  • Starts automatically when you open a saved .tex project.
  • Each open project keeps its own session and preview position when you switch tabs.
  • Page navigation, zoom, Pause/Resume, Stop, Restart, Output and Sync.
  • Command-click in the preview (Ctrl-click on Windows or Linux) jumps to the source line.
  • Turn it off under View → Show → Live Preview.

Relation to TeXstudio

Apart from the preview, the editor is TeXstudio: completion, syntax and reference checking, structure view, and the usual build commands, which you still use for the final PDF.

Requirements

  • A TeX Live installation (on macOS, for example MacTeX) or MiKTeX, which provides the packages.
  • The TeXpresso engine is bundled.
  • macOS 15 or newer; or 64-bit Linux with glibc 2.38 or newer and the system libraries listed in the release requirements.
  • On Windows, live compilation runs inside WSL2; see the setup guide and requirements.

Installation

  1. Install TeX Live or MiKTeX if you do not have it. On Windows, install it inside WSL2.
  2. Download the release for your platform above. On macOS, extract the signed, notarized app and move it to Applications. On Windows, extract the ZIP and run texstudio.exe (the Windows build is unsigned). On Linux, install the .deb with your package manager.
  3. Open a saved .tex file. The preview appears next to the editor.

To build from source, see the build instructions.

Other TeXpresso-based editors

  • Visual Studio Code — an extension using the same pinned TeXpresso engine as TeXstudio Espresso.
  • Emacs — texpresso-view embeds the preview inside Emacs; the original mode uses a separate viewer.
  • Neovim — texpresso.vim, with marksetta.nvim adding live preview for Marksetta documents.
  • Vim 9 — a Vim9script port of the Neovim integration.
  • Zed — the TeXpresso extension and the newer TeXpresso Live development extension.
  • TeXLocal / Underleaf — a native macOS editor with experimental TeXpresso live preview.
  • Typr — a browser editor with experimental TeXpresso preview through its optional companion service.
